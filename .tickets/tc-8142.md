# A narrow-box dimming test fails on Linux: the card stores the history length one half-float step above the nearest

On the cloud worker (Linux, RTX 2000 Ada, NVIDIA), AccumulatorRenderTests.UnderTheNarrowBoxADimmingStepShortensTheHistoryByTheClampsMoveOverHalfTheMeansLight reads the history length 9.9921875 where it expects 9.984375, one half-float step (2^-7) higher (t0-5tyj take T18, 2026-11-22, the line's head 0e441286d, shard 1 of 6 of the Checked Rendering tests). The test is the line's (Design X); main has no test of that name. Every other test of the 3,340 passed or was skipped, and no test failed on a validation message. The test's comment derives 9.984375 as the half float nearest the exact length 9.983 from the stored 0.9502 and 0.7998. On the card, the inputs or the length's own store round differently, so the test's exact value is a Mac result. Fix: find which store differs on the card (the slow and fast means, or the length), then either make the store's rounding the same on both (half_store.glsl) or let the test allow one half-float step, as t8-v31a did for a NVIDIA store toward zero.

## Acceptance Criteria

The test passes on the Mac and on the cloud worker, and its comment names which store rounds and how.


## Notes

**2026-11-23T00:52:01Z**

The cause and the fix (acceptance lead, 2026-11-22). No store differed. The clamp's σ did.

- Red, card job 31ba72a6-4de4-4c1c-975f-2eefd4e4cf1b-u2 (RTX 2000 Ada, Linux, $0.0314, 126 s) on the scratch commit 122264e25: the test read 9.9921875. A scratch diagnostic repeated it with ClampSigmas = 0 and read 9.984375, the Mac's value. The light and the fast history read 0.7998047 on the card and on the Mac. The Mac gives 9.984375 both ways.
- The cause: sigma = sqrt(max(squares / count - mean * mean, 0)) over the 9 equal fast histories cancels to about 1e-4 of the light on the card, not to 0. The narrow box then stops 2σ above the mean, so the lag is smaller and the length one half-float step higher.
- The fix (accumulate_spatial.comp): the moments are taken around the pixel's own fast history. Equal neighbors give offsets of exactly 0, so a flat box has σ = 0 under any rounding. The filter's young-history variance (diffuse_filter_variance.comp:42) already had this form. tc-l0jm makes one shared function of the two.
- Green, card job a8d320d8-9261-4e90-b29e-f953123cdbad-u2 ($0.0660, 342 s) on the scratch commit of the fix: AccumulatorRenderTests and its nested classes, 144 passed, 0 failed. Mac: the full Checked Rendering suite, 3,417 passed, 0 failed, 10 skipped. No test failed, so no value moved past a tolerance. A value that moved inside its tolerance does not show in a pass.
