# The survey's probe patch does not apply to main since the back-face layer: its hunk of SpecializationStorage.Count expects 11, and main has 12

Found by t0-gbgj on 2026-11-22. Main at 284025851 added the specialization constant BothFaces (id 7) and raised SpecializationStorage.Count in src/Tertius.Rendering/ShaderConstants.cs from 11 to 12. tools/renderer-survey/probe.patch of main still holds the hunk '-    public const int Count = 11; +    public const int Count = 12;', so 'patch' fails on 1 of the 2 hunks of ShaderConstants.cs, and 'renderer-survey.py probe-build' fails on main. The fix: the hunk becomes '-Count = 12' / '+Count = 13' (the probe adds one row, probeSignal at id 12). t0-gbgj built its main side M2 with that one-line fit as a scratch patch (docs/research/t0-gbgj-combined-check/scratch-probe-m2.patch). The line t7-3e22 fixes its own patch in the merge of t0-gbgj (Count 12 -> 14, two probe rows). So this bug closes when that line merges into main, or by the one-line fit on main if main needs a probe first.
