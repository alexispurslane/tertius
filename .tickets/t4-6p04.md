# One light loop per light shape: give the tube lights their own loop

lighting.glsl has one loop for the rectangle lights and one for every other light, so the tube light's code sits in the loop of the point and spot lights. The proposal of 2026-11-09 (step 3) infers that this made the deck's direct pass 0.76 ms slower (1.694 to 2.457 ms). Give the tube lights a loop of their own, as the rectangles have, so that each copy of the loop holds the code of one light shape. The image stays the same. Measure the direct pass with a Metal System Trace before and after on the exit deck and a scene with a tube light.
