# The accumulator's clamp test reads 1.2490234 against 1.25 on NVIDIA

AccumulatorRenderTests.AStepOfTheSampleShortensTheHistoryByTheClampsMoveOverHalfTheMeansLight fails on the RTX 2000 Ada: the history holds 1.2490234, one half-float step below the exact 1.25.


## Notes

**2026-11-12T21:52:41Z**

Kind (a), a value that the driver may round either way. The history should hold exactly 1.25; NVIDIA stores 1.2490234, the next half float below. Vulkan leaves the rounding of a float to a lower-precision format undefined (round to nearest or toward zero, spec 'Floating-Point Format Conversions'), and allows float division 2.5 ulp off. So a float result a hair below 1.25 can be stored one half-float step lower. Fix: the test allows one half-float step, 2^-10, at 1.25. The bound still catches the fault that the test exists for: without the clamp the value is 1.0625, 192 steps away.
