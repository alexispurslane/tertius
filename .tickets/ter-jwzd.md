# Content formats: blueprints and scenes

Design: docs/plans/content-formats.md.


## Notes

**2026-10-17T13:22:10Z**

User preference (2026-10-17): any vehicle that can carry things and move should be a semantic frame by default, so that the bodies resting in it are at rest in its own system, with no creep or jitter from its motion. Blueprints should make that the default for such content, for example a body with an interior, rather than leaving AsFrame to each author.
